Privacy

Last updated November 5, 2026.

Mergelio is a desktop Git client that runs on your computer. It has no user accounts and no Mergelio server. This page explains what the app and this website do with your data.

The app

  • Your repositories stay on your machine. Mergelio reads and changes them by running the Git already installed on your computer. Nothing from your repositories is sent to us.
  • No usage data or crash reports are collected. The app does not track how you use it.
  • Update checks. The app reads a small update feed from the project on GitHub (github.com/senseyman/mergelio) to see if a new version exists, and fetches updates from there. GitHub sees your IP address, as with any request to it.
  • Git remotes. When you fetch, pull, push or clone, Git connects to the remote you configured (for example GitHub, GitLab or your own server). Those services handle that traffic under their own privacy policies.
  • GitHub and GitLab accounts. If you connect an account to see pull requests, merge requests and CI status, the app talks directly to that service’s API. Your access token is saved through Git’s own credential helper, the same place Git keeps your passwords (for example Keychain on macOS or Git Credential Manager on Windows, depending on how your Git is set up), and is only sent to the server it belongs to.
  • Settings such as recent repositories and preferences are stored locally on your computer.

This website

  • mergelio.com is a static page hosted on GitHub Pages. It uses no cookies, no analytics and no third-party scripts, and its fonts are served from this site.
  • GitHub, as the host, may log technical data such as your IP address to run and protect the service. See the GitHub Privacy Statement.
  • Mergelio itself is published on GitHub, which is covered by the same statement.

Contact
