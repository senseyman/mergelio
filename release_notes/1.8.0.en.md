# New

## Highlights

- **Bisect from the graph.** Run a whole bisect without leaving Mergelio.
- **Unattended bisect.** Hand the hunt to a command and let git find the first bad commit.
- **One right-click menu per commit row.**
- **Faster graph.** It no longer waits for squash-merge connectors.

## Bisect

- While a bisect is in progress, a bar above the list shows how many revisions and steps remain, the commit under test, and the buttons Good, Bad, Skip, Log and Reset bisect.
- Each commit row shows its verdict as a tinted node and a text pill (good, bad, skip), so nothing relies on colour alone.
- The commit menu gains **Start bisect from here**, **Mark as good**, **Mark as bad** and **Skip this commit**.
- When the range narrows to one commit, the bar becomes a **First bad commit** card with Jump to commit, Copy SHA, Copy fixup! and Revert this commit. For a merge commit you are asked which parent to keep.
- A bisect started in a terminal, or left over from an earlier session, shows up exactly the same way. Repositories that use other terms (old/new) are supported.
- Starting a bisect is refused when the working tree has uncommitted changes.
- Quitting or closing the repository during a bisect asks first, with Reset bisect, Continue anyway and Cancel.
- **Run a command…** appears once both ends of the range are marked. Enter a command, and the dialog shows the exact line that will run. Git then tests every commit with it. It is not remembered between uses.
- While it runs, the bar names the command and the verdict buttons are hidden. Cancel is in the status bar. The candidate count and the verdicts on the graph update as the hunt narrows.
- Each ending is explained in plain words: every remaining commit skipped, a command that cannot be run, a command that modified tracked files, a cancelled run (the marks so far are kept), and a found commit.
- A run is refused when the working tree has uncommitted changes, because testing uncommitted code gives wrong answers.
- While a run is live, marking, skipping and resetting are blocked.
- Cancel stops git only. Anything your command already started keeps running.

## Graph

- Right-clicking a commit row now opens the same menu in the branch column and the commit column. The names of the branches on that row come first in the copy group, including those hidden behind the "+N" chip.
- The graph, branch list and working tree now update as soon as history is read after a commit, pull, reset, checkout or undo. The squash-merge connectors join in afterwards. Repositories with many branches feel much quicker.
