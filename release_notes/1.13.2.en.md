# New

- **Restore a file from any commit.** Right-click a file in a commit's changed files and choose **Restore this version** or **Restore version before this commit**, or right-click a row in **File history**. Only the working tree changes: what you staged stays staged, and nothing is committed. One undo puts back what was there. A commit that doesn't have the file is refused rather than deleting your copy.
- **Clean up branches.** **Clean up branches…** in the **Branches** section's `⋯` menu, or in the command palette, lists local branches merged into your main branch, untouched for 90 days, or whose upstream is gone. Tick them and delete them in one step, and one undo brings them all back. **Select merged** picks only the merged ones.
- **Filter branches.** Click the search icon in the **Branches** header and type. Every word must appear in the branch name, and folders holding a match open while you filter. Press `Esc` to clear it.
- **Hide or solo branches in the graph.** Right-click a branch, local or remote. **Hide in graph** drops the commits only that branch reaches; **Solo in graph** shows just that branch and its history. A bar above the graph says what is hidden, and **Show all** brings everything back. Your choice is kept for each repository.
- **Markdown preview.** Switch a `.md` file between **Source** and **Preview** in the diff and in the Files browser. In a side-by-side diff, both versions are shown rendered. Links open in your browser, and images from the internet are not loaded.
