# Changed

- **The Windows installer is signed.** `setup.exe`, Mergelio itself, its libraries and the uninstaller now carry a Certum code signing certificate issued to Serhii Kotenko, with a timestamp so the signature stays valid after the certificate expires. Windows names the publisher instead of showing "Unknown publisher", and right-click → **Properties → Digital Signatures** shows the certificate. SmartScreen also weighs how often a file has been downloaded, so a new release can still warn for a while; **More info** now shows who signed it.
- The publisher shown by the Windows installer and in **Apps & Features**, the macOS copyright and the Linux package metadata now read Serhii Kotenko instead of Neo. An existing install still upgrades in place.
