# Змінено

- **Інсталятор для Windows підписано.** `setup.exe`, сам Mergelio, його бібліотеки й деінсталятор тепер підписані сертифікатом Certum для підпису коду, виданим на ім'я Serhii Kotenko, з позначкою часу, тож підпис лишається дійсним і після завершення строку дії сертифіката. Windows показує ім'я видавця замість «Невідомий видавець», а в контекстному меню **Властивості → Цифрові підписи** видно сам сертифікат. SmartScreen зважає ще й на те, як часто файл завантажують, тому новий випуск якийсь час може показувати попередження; тепер **Додаткові відомості** показують, хто його підписав.
- Видавець в інсталяторі Windows і в **Програмах і компонентах**, авторські права на macOS і метадані пакетів для Linux тепер указують Serhii Kotenko замість Neo. Наявна інсталяція й надалі оновлюється на місці.
