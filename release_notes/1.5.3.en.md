# New

## Highlights

- **Merge and pull options.** Squash or stage a merge without committing, prefer one side on conflicts, and pull fast-forward only or with autostash.
- **Safer clone and credentials.** Clone can be cancelled, and Mergelio now asks for passwords and passphrases instead of failing.
- **Faster history.** Large repositories load the graph in pages and skip reloads when nothing moved.

## Merge and pull

- Merge offers **Squash (stage, do not commit)** and **Stage the merge, do not commit**. Both stop with the changes staged. Nothing is committed and the toast says so.
- Merge also has **If both sides changed the same lines**: Ask, Ours or Theirs.
- Aborting a conflicted squash now works.
- Pull offers **Pull (fast-forward only)** and **Autostash on pull**.
- The pull strategy you chose in Preferences is now actually used. Plain Pull follows it, the menu offers the other strategy, and the command palette uses the same defaults.

## Clone and credentials

- Clone now shows progress you can cancel, and fetches submodules. An abandoned clone cleans up after itself, so you can retry. A dead host no longer freezes it for 15 minutes.
- Pushing a tag gets the same protection.
- When Git needs a password or a key passphrase, Mergelio opens a small prompt window. Before, it failed with an unclear error. Closing the window or pressing Escape refuses the request.

## Graph

- The graph loads 2000 commits at a time. A row at the bottom loads more when the history is longer.
- Refreshing after a file save or a fetch that changed nothing no longer reloads the whole history.

# Fixed

- A rebase pick that applied to nothing, usually a commit already squash-merged into the base, aborted the whole rebase and threw away the commits already replayed. The rebase now pauses, and Continue skips that step.
