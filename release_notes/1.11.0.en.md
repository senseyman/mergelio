# New

## Highlights

- **Multi-repo dashboard.** See every repository in the current group on one screen. Fetch them all or fast-forward them in one batch.
- **Conflict navigation.** Jump between conflicts in the merge tool with ⌥↑ / ⌥↓.
- **Rebase editor upgrades.** Autosquash, exec and break steps, and moving stacked branches along with the rebase.
- **Commit composer.** Commit templates, Conventional Commits mode, trailers, and drafts saved per branch.

## Multi-repo dashboard

- Open it from the new toolbar toggle beside Files/History, with **⌘⇧D**, or with "Open dashboard" in the command palette.
- Each row shows the branch, ahead/behind counts, changed, conflicted and untracked files, stashes, and how long ago the last fetch ran.
- Rows flag a merge, rebase, cherry-pick, revert, am or bisect in progress. They also flag branches with no upstream or a deleted upstream.
- Click a row to open that repository.
- **Fetch all** fetches four repositories at a time and shows progress for each. It skips repositories without a remote, never overlaps auto-fetch, and can be cancelled from the status bar.
- **Pull fast-forwardable** updates only the repositories that can fast-forward cleanly. It never merges, rebases or commits. Each skipped repository is listed with the reason: uncommitted changes, diverged, no upstream, operation in progress, and so on.
- While the dashboard is open, shortcuts, the toolbar, the status bar and the palette don't act on a repository you can't see. The palette offers "Go to <repo>" for each repository instead.
- Credential prompts now name the repository they are for, and the prompt window no longer overflows.

## Merge tool: conflict navigation

- A bar above the hunks shows "N conflicts" or "Conflict 2 of 7", with previous and next buttons.
- Each jump scrolls the conflict to the top and wraps around at either end. **⌥↑ / ⌥↓** do the same, except while you are typing in a hunk editor.
- Switching to another file starts from the top again.

## Interactive rebase

- **Autosquash switch.** `fixup!` and `squash!` commits move under the commit they name, and the editor shows each pairing. Turning the switch off, or picking a preset, puts the commits back.
- **Exec and break steps.** Add, drag and remove them in the commit table. Every exec command is shown word for word and needs your confirmation before the rebase starts.
- **Update stacked branches.** Local branches stacked on the rebased commits move with them. Branches checked out in any worktree are left alone. Needs git 2.38 or newer.
- **Stops are explained.** A break, a failed exec, or a reword rejected by a hook now pauses the rebase. The Changes panel says why it stopped and shows the failed step's output behind a toggle. You can still commit a fix before continuing. This works for rebases started in a terminal too.
- **Long exec steps.** Rebases that run exec commands get a 2-hour limit and a Cancel button on the busy bar.
- **"Prepare fixup for this commit"** in the graph context menu fills the composer with `fixup! <subject>`. Nothing is committed for you.

## Commit composer

- An empty commit message starts from the repository's template: one saved in Mergelio for the repository, else git's `commit.template`, else a `.gitmessage` at the repository root. Open **Message template…** in the composer menu to edit it. Comment lines are stripped, and a message left exactly as the template offered is refused, as git refuses it.
- **Conventional Commits** mode is optional and set per repository. It adds a type picker, a scope field and a **Breaking** toggle in front of the summary. A live counter checks the summary against a limit of 50, 72 or 100 characters. A menu action wraps the description to 72 columns and leaves lists, quotes, code and trailer lines alone.
- **Trailers** replaces "+ Co-author" and adds Refs and Fixes, completed from the forge's open issues when a forge is set up. The **Sign off** toggle adds a `Signed-off-by` line for your profile identity. Undo and redo of a commit remember these options.
- **Recent messages** lists messages you committed from Mergelio, so you can recall one.
- An unfinished message is kept for each branch. It survives a branch switch, closing the composer and restarting the app.

# Fixed

- A `break` step was reported as a finished rebase, with an undo entry covering only half of it.
- **Continue** at such a stop could fall back to `rebase --skip`, which throws away unstaged edits. It now always uses `--continue`.
