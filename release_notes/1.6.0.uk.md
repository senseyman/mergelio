# Нове

## Головне

- **Перегляд reflog.** Поверніть коміт, на який більше не вказує жодна гілка, не відкриваючи термінал.
- **Пулреквести.** Бічна панель показує відкриті пулреквести репозиторію зі станом CI кожного.
- **Тікети.** Відкриті тікети теж показано в бічній панелі, разом з їхніми мітками.

## Reflog

- У бічній панелі репозиторію зʼявився розділ **Reflog** зі записами reflog для HEAD: сам запис, дія, яку зафіксував git, решта повідомлення та дата.
- Для кожного запису доступні: переключитися, створити гілку тут, обидва скидання та копіювання SHA.
- Перед переключенням буде запит на підтвердження, бо HEAD стане відокремленим (detached).
- Розділ згорнутий за замовчуванням і нічого не читає, доки його не відкрити. Після кожної завершеної дії він оновлюється.
- Якщо reflog не вдалося прочитати, розділ каже про це, а не показує порожній список. Якщо список обрізано, про це також повідомляється. Коли записів понад двадцять, зʼявляється фільтр.

## Пулреквести і тікети

- Для репозиторіїв із віддаленим GitHub бічна панель показує відкриті пулреквести. У рядку видно стан CI, автора, скільки часу минуло і гілку, з якої надіслано запит. Цільову гілку показано лише тоді, коли це не головна гілка репозиторію.
- Натисніть червоний значок перевірки, щоб побачити назви перевірок, які не пройшли.
- Розділ **Тікети** показує відкриті тікети з мітками, автором і віком. Рядок відкриває тікет у браузері. Якщо в репозиторії вимкнено відстеження тікетів, розділ просто порожній.
- Підключіть токен GitHub у Налаштування → Облікові дані. Токен зберігає credential helper самого git, тож Mergelio не тримає власних секретів.
- Без токена GitHub дозволяє 60 запитів на годину, і панель про це повідомляє. Без токена нічого не оновлюється саме.
- Пулреквести оновлюються після fetch, pull або push. З токеном вони також оновлюються за таймером, поки вікно у фокусі. Тікети оновлюються після fetch, pull або push і без токена.
- Репозиторії без віддаленого GitHub нічого з цього не показують.
