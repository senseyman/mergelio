# Нове

## Автоматичні оновлення

- Mergelio один раз питає, чи можна перевіряти GitHub на нові версії. Далі перевіряє щодня.
- Коли виходить новий реліз, над рядком стану з'являється смужка.
- У macOS і Windows оновлення встановлюється саме. У Linux смужка веде на сторінку завантаження, бо встановленням керує менеджер пакетів.
- Перед заміною запущеного застосунку оновлення перевіряється.
- Встановлення чекає, поки Git зайнятий, тож оновлення не закриє застосунок посеред rebase.
