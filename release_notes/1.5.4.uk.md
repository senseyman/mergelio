# Нове

## Порівняння двох комітів або гілок

- Позначте будь-який коміт у графі через **Позначити для порівняння**, а потім виберіть другий через **Порівняти з <ref>**. Також можна скористатися **Порівняти з поточною** на гілці в бічній панелі.
- Права панель перелічує всі файли, що відрізняються. Відкриття файлу показує diff лише для читання, а в заголовку названо обидві сторони.
- Порівняння слідує за ref-ами, коли ви робите коміт, злиття чи отримання. Незакомічені зміни воно ігнорує.

# Змінено

- Великі репозиторії з багатьма гілками оновлюються набагато швидше. Створення гілки та перемикання на неї тепер перезавантажує один раз замість двох.

# Виправлено

- Перейменований файл у diff коміту чи порівнянні показувався як зовсім новий. Тепер він показується як перейменування.
- У macOS застосунок, зібраний без сертифіката підпису, закривався одразу після запуску з помилкою "Library not loaded". Такі збірки тепер запускаються.
