# New

- **Split a commit.** Right-click a commit on the current branch and choose **Split commit…**. Mergelio pauses a rebase on that commit and puts its changes back in the working tree, unstaged, with the original message already in the commit box. Stage and commit the changes in as many parts as you like, then continue from the Changes panel. Mergelio never commits for you, and aborting puts the branch back exactly as it was. Local branches based on the commit, or on commits after it, move along with it. Root commits, merge commits and commits under a merge can't be split. If the commit is already on a remote, Mergelio asks first, as it does for rewording one.
- **Read issues in Mergelio.** Clicking an issue in the sidebar's **Issues** section opens it in the middle column in place of the graph. It shows the number, title, state, author, age, labels and the description rendered as Markdown, with buttons to refresh it, open it in your browser or close it. Opening an issue closes a pull request review, and the other way round.
- **Proxy settings.** Behind a proxy, git worked but the pull request panel and update checks didn't, because Mergelio's own requests always connected directly. They now use the same proxy git does: `http.proxy` from git's global or system config, then the `HTTPS_PROXY`, `http_proxy` and `ALL_PROXY` environment variables, skipping hosts in `NO_PROXY`. **Preferences → Network** shows which proxy is in use and which setting chose it, and lets you type a proxy URL or turn the proxy off instead. For a typed URL or no proxy, **Use this setting for git commands too** applies the same choice to fetch, pull, push and clone over https (git 2.31 or later). ssh remotes are not affected, and the tab lists them. SOCKS and `https://` proxies aren't supported for Mergelio's own requests, which go direct, and the tab says so.
- **Open recent from the tab bar.** The **+** beside the tabs now has an **Open recent** submenu that lists your recent repositories, pinned ones first. Repositories already open in a tab are left out.

# Changed

- **Clicking a pull request now reviews it in Mergelio.** A click on a row in **Pull requests** (**Merge requests** on GitLab) opens the request in the branch review instead of the browser. To open it on GitHub or GitLab, right-click the row and choose **Open in browser**. The **Review in Mergelio** menu entry is gone, since a click does the same thing.
- If you type a password into the manual proxy URL, it is stored in plain text in Mergelio's settings database.

# Fixed

- Undoing a rebase that moved other local branches along with it now moves those branches back too, unless you've moved or deleted them since. Redo moves them forward again.
- Redo of a finished rebase, cherry-pick or revert no longer throws away uncommitted changes. It now refuses and asks you to commit or stash them first.
