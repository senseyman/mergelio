# New

- **More you can do with a tag.** Right-click a tag in the sidebar. **Checkout (detached HEAD)** checks out the tagged commit, even when a branch has the same name as the tag. **Create branch from tag…** makes a branch at the tagged commit without switching to it.
- **Rename a tag.** **Rename…** in a tag's menu gives it a new name. An annotated tag keeps its message, tagger and date, and a signed tag keeps its signature. If the new name is taken, nothing changes. One undo puts the old name back.

# Fixed

- After you created a branch on your main branch's latest commit and switched to it, the graph's branch column showed the new branch one row lower, as if it started at the commit before. The column now keeps your main branch's name on its history, and a commit whose branches are already named on the row above no longer looks like the start of a branch.
