# New

## Highlights

- **Git LFS support.** LFS files now show their real content instead of pointers. Pull, fetch, prune, track, convert and lock them without a terminal.
- **Drag a branch onto a branch or commit.** Merge, rebase, fast-forward, reset, move and more from one menu, with a confirmation first.
- **Repository maintenance.** See what makes a clone big and clean it up safely.

## Git LFS

- LFS files no longer look like three lines of pointer text. A diff of LFS files shows a card with what changed, each side's size and object id, and whether the object is downloaded.
- **Edit** is hidden on an LFS diff, so you can't accidentally commit a hand-written pointer over a real file.
- Everything LFS-related appears only when the repository uses LFS and `git-lfs` is installed. Repositories without LFS are unaffected.
- **Pull LFS files** and **Fetch all LFS objects** are in the Pull/Fetch menus and the command palette. Both can be cancelled.
- A strip in the working tree counts files that are still pointers and downloads them in one click. Sides marked "Not downloaded" in a diff get a **Download** button.
- **Prune LFS objects…** always shows a preview first and deletes only after you confirm.
- The working-tree file menu can track a file or its extension, stop tracking a pattern, and convert files that are already committed. Convert stops at staged. Nothing is committed for you.
- Before a push that uploads commits, Mergelio checks that the LFS pre-push hook is in place. If it isn't, you can install the hooks and push, push anyway, or cancel.

## LFS file locks

- LFS files in the working tree, commit details and compare show a lock chip: "You" for your own locks, or the owner's name for someone else's.
- The file menu offers **Lock file**, **Unlock file** and, for someone else's lock, **Force unlock…**. Force unlock always asks for confirmation and names the owner.
- A Locks section under the LFS strip lists your locks and others', with Unlock / Force unlock for each and a Refresh button.
- A push that includes files locked by other people warns you and lists them. Choose **Push anyway** or Cancel.
- If the server doesn't support locking, Mergelio says so once and stops asking.

## Drag a branch

- Pick up a branch label on the graph or a branch in the sidebar and drop it on another branch or on a commit. A menu offers what makes sense for that drop.
- Onto a branch: merge, rebase, fast-forward, and reset (soft, mixed or hard) or move the branch.
- Onto a commit: rebase, reset or move, cherry-pick that commit onto the dragged branch, or create a branch there.
- A remote branch, as source or target, offers only merge or rebase.
- Every option asks for confirmation and says what it will do. Hard reset and move follow your destructive-action preference.
- The sidebar's drop menus now use the same menu, so they gain the new options and the confirmation.
- Undo entries now show full branch names instead of cutting them short.

## Repository maintenance

- Open **Repository maintenance…** from the command palette. The panel only reads when it opens. Every change asks first.
- Storage shows the git directory split into packs, loose objects, LFS objects and everything else.
- Largest files in history lists the 25 biggest files with the commit that added each. Run the scan when you want it, cancel it any time. A result you've already seen is shown right away and marked out of date once refs change.
- Branches lists ones already merged into the main branch and ones with no commits for 90 days or whose upstream is gone. Delete them in bulk with one undo entry. Branches held by a worktree can't be picked.
- Worktrees shows how many can be pruned. Reflog shows how many entries the next gc would expire.
- **Run gc** and **Run maintenance** ask for confirmation, can be cancelled from the status bar, and are refused while a fetch is running. Afterwards the panel shows the size change.

## Diff sheet

- The header and hunk action buttons fold into a **More actions** menu when the sheet is too narrow for them.
- The Inline/Split toggle is now translated.

# Fixed

- Opening an LFS file no longer looks like it was truncated to nothing.
- An app started from the Dock or Finder could not find tools installed beside git, such as `git-lfs` in Homebrew. LFS diffs then showed pointers. Those tools are now found.
- A revision name that looks like a command-line option could be passed to git as an option. It is now refused or guarded.
- Fetching, pulling and cloning now cancel every git command they started, not just the last one.
