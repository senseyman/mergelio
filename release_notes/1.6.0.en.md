# New

## Highlights

- **Reflog viewer.** Recover a commit that no branch points at any more, without opening a terminal.
- **Pull requests.** The sidebar lists a repository's open pull requests with the CI state of each.
- **Issues.** Open issues are listed in the sidebar too, with their labels.

## Reflog

- A new **Reflog** section in the repository sidebar lists the entries of the HEAD reflog: the entry, the action git recorded, the rest of its message and the date.
- Each entry offers check out, create a branch here, both resets and copy SHA.
- Checking out asks for confirmation first, because it leaves HEAD detached.
- The section starts collapsed and reads nothing until you open it. It refreshes after each completed action.
- If the reflog cannot be read, the section says so instead of showing it as empty. When the list is cut short, it tells you. With more than twenty entries you get a filter.

## Pull requests and issues

- The sidebar lists open pull requests for repositories with a GitHub remote. Each row shows the CI state, who opened it, how long ago, and the branch it comes from. The target branch is shown only when it is not the repository's main branch.
- Click a red check badge to see the names of the checks that failed.
- The **Issues** section lists open issues with their labels, their author and their age. A row opens the issue in your browser. If a repository has switched its issue tracker off, the section is simply empty.
- Connect a GitHub token in Preferences → Credentials. The token is kept by git's own credential helper, so Mergelio stores no secret of its own.
- Without a token GitHub allows 60 requests an hour, and the panel says so. Without a token, nothing refreshes by itself.
- Pull requests refresh after a fetch, pull or push. With a token they also refresh on a timer while the window has focus. Issues refresh after a fetch, pull or push even without a token.
- Repositories without a GitHub remote show none of this.
