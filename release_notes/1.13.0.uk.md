# Нове

## Головне

- **Нотатки git.** Додавайте нотатку до будь-якого коміту, не змінюючи його, і діліться нотатками через віддалений репозиторій.
- **Відкриття у ваших інструментах.** Відкривайте файл у редакторі, інструменті порівняння чи інструменті злиття просто з Mergelio.
- **Підписані теги.** Підписуйте тег під час створення й читайте повідомлення кожного тега в подробицях коміту.
- **Налаштування репозиторію.** Редагуйте git config репозиторію в Налаштування → Репозиторій.
- **Повідомлення вашою мовою.** Сповіщення, прогрес і підписи скасування тепер відповідають мові застосунку.

## Нотатки git

- Клацніть коміт у графі правою кнопкою й виберіть **Додати нотатку…** або **Редагувати нотатку…**. Збереження порожньої нотатки видаляє її, а **Видалити нотатку** видаляє її одразу.
- Подробиці коміту показують його нотатку з кнопками для редагування, копіювання й видалення.
- Додавання, редагування й видалення нотатки можна скасувати.
- Нотатки залишаються на цьому комп’ютері, доки ви ними не поділитеся. Меню віддаленого репозиторію на бічній панелі, палітра команд і меню **Отримати** пропонують **Відправити нотатки** та **Отримати нотатки**, а в діалозі відправлення є **Також відправити нотатки**.
- Отримані нотатки зливаються з вашими, тож двоє людей можуть додавати нотатки в одному репозиторії. Якщо ви обидва залишили нотатку до одного коміту, зберігаються обидва тексти.
- Увімкніть **Отримувати нотатки з кожним отриманням** у Налаштуваннях або позначте це в меню **Отримати**, щоб нотатки кожного віддаленого репозиторію надходили з кожним отриманням, зокрема автоматичним. Типово вимкнено.
- Нотатки ніколи не з’являються як коміти в графі чи результатах пошуку.

## Відкриття в редакторі, інструменті порівняння й інструменті злиття

- **Відкрити в редакторі** доступно на панелі змін, у подробицях коміту, у перегляді порівняння та в переглядачі файлів. З неіндексованого боку порівняння файл відкривається на першій зміні.
- Редактор вибирається в Налаштування → Загальні → **Відкривати файли в**: системна програма, VS Code, IntelliJ IDEA або власна команда. Власна команда може містити `{file}` і `{line}` і запускається напряму, ніколи через оболонку.
- **Відкрити в інструменті порівняння** запускає `git difftool` з інструментом, заданим у git config, для змін у робочому дереві, коміту чи порівняння. Одночасно можна відкрити до чотирьох.
- **Відкрити в інструменті злиття** запускає `git mergetool` для файлу з конфліктом. Коли інструмент повідомляє про успіх, git індексує файл, і Mergelio на цьому зупиняється, тож злиття ви завершуєте самі. Розв’язання останнього файлу завершує сеанс так само, як **Вирішити**.
- Якщо інструмент порівняння чи злиття не задано, Mergelio про це повідомляє й показує команду git, яка його задає.
- Редактори й інструменти знаходяться, навіть коли Mergelio запущено з Finder або Dock.

## Підписані теги

- Діалог створення тега має **Підписати тег** і необов’язковий **Ключ підпису**. Підписаний тег завжди анотований.
- «Підписати тег» увімкнено одразу, якщо ваш git config вимагає підписаних тегів (`tag.gpgSign` або `commit.gpgsign`).
- Автором тега стає особа активного профілю, як і для комітів. Підписування чекає на ваш пароль, а на панелі зайнятості є кнопка **Скасувати**.
- Подробиці коміту показують автора, дату й повідомлення кожного анотованого тега поруч із перевіркою підпису. Тег, який не вдалося прочитати, повідомляє про це, а не зникає.

## Налаштування репозиторію

- У Налаштуваннях з’явилася вкладка **Репозиторій** для репозиторію на екрані. На ній ім’я та пошта, rebase під час pull, встановлення upstream під час першого відправлення, очищення під час отримання, перетворення кінців рядків, **Підписувати коміти** та rerere.
- Кожен рядок показує значення, яке використовує git, і звідки воно береться: система, глобальні налаштування, цей репозиторій, worktree чи командний рядок. Наведіть курсор, щоб побачити файл.
- Зміни зберігаються в **Цей репозиторій**, якщо ви не виберете **Глобально**. **Успадкувати** прибирає значення з вибраного місця, і знову діє значення з ширшої області.
- Там, де Mergelio перевизначає налаштування, вкладка про це каже. Наприклад, для комітів у Mergelio використовується особа активного профілю.

## Повідомлення вашою мовою

- Сповіщення, підписи на панелі зайнятості та підписи скасування для всіх дій, клонування, створення репозиторію й генерування ключа SSH тепер відповідають мові застосунку. Раніше вони завжди були англійською.
- Зміна мови діє з наступного повідомлення.
- Текст, який виводить сам git, показується так, як його написав git.

# Виправлено

- Коли в git config задано `tag.gpgSign`, створення легкого тега не вдавалося, а анотовані теги підписувалися без вашого запиту. Тепер тег підписується лише тоді, коли увімкнено **Підписати тег**.
- Скасування видалення тега тепер повертає початковий тег із його повідомленням, автором і підписом.
