# New

## Compare two commits or branches

- Mark any commit in the graph with **Mark for comparison**, then pick a second one with **Compare with <ref>**. You can also use **Compare with current** on a branch in the sidebar.
- The right panel lists every file that differs. Opening a file shows a read-only diff, with both sides named in its header.
- The comparison follows the refs when you commit, merge or fetch. It ignores uncommitted changes.

# Changed

- Large repositories with many branches refresh much faster. Creating a branch and checking it out now reloads once instead of twice.

# Fixed

- A renamed file in a commit diff or comparison showed as a brand-new file. It now shows as a rename.
- On macOS, an app built without a signing certificate quit on launch with "Library not loaded". Such builds now start.
