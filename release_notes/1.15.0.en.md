# New

- **Review a pull request in Mergelio.** Right-click a row in **Pull requests** (**Merge requests** on GitLab) and choose **Review in Mergelio**. The request opens in the branch review with its commits, changed files and viewed marks, compared from the branch point the way GitHub and GitLab show it. A panel above the diff shows the request's state, title, author and branches, the CI jobs for the commit on screen, and the description rendered as Markdown, with an **Open in browser** link. Reviewing is read-only: your working tree, local branches and remote-tracking branches stay as they were, and nothing is sent to the forge. If the request is pushed to or retargeted while you read, the panel says so and asks you to reopen it. A plain click on the row still opens it in your browser.
- **Desktop notifications.** While Mergelio is in the background it can tell you when a fetch, pull, push or clone that took longer than 10 seconds finishes, with the reason if it failed. It can also tell you when CI passes or fails on your current branch or on an open pull request, and when a pull request is opened, merged or closed. Clicking a notification brings Mergelio to the front on that repository's tab, and pull request and CI notifications also open the request for review. Notifications are off by default. Turn them on in **Preferences → Notifications**, where each kind has its own switch and the "long operation" threshold can be set to 5, 10, 30 or 60 seconds. **Preferences → Repository** can override each kind for one repository. With notifications on, Mergelio checks GitHub or GitLab in the background only for open repositories, pauses while its window is focused, and slows down when the rate limit runs low. With them off, it makes no background requests.
- On macOS, if no notifications appear, allow them for Mergelio in **System Settings → Notifications**. On Windows, turning notifications on for the first time adds a Start menu shortcut, which Windows needs in order to show them. On Linux, clicking a notification doesn't switch tabs yet.

# Changed

- **Checking out a pull request no longer moves remote-tracking branches.** It used to update `origin/main` along the way, or `origin/pr/<n>` if your remote maps pull request refs. Now it only fetches the commits it needs.
- On Linux, Mergelio now needs libnotify. The `.deb` and `.rpm` packages pull it in. To build from source, install `libnotify-dev` (Debian, Ubuntu) or `libnotify-devel` (Fedora).
