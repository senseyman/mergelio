# Нове

- **Перегляд пулреквесту в Mergelio.** Клацніть правою кнопкою рядок у **Пулреквестах** (**Запитах на злиття** на GitLab) і виберіть **Переглянути в Mergelio**. Запит відкривається в огляді гілки з комітами, зміненими файлами й позначками «переглянуто», у порівнянні від точки розгалуження, як це показують GitHub і GitLab. Панель над диффом показує стан запиту, заголовок, автора й гілки, завдання CI для коміту на екрані та опис, відформатований як Markdown, а також посилання **Відкрити у браузері**. Перегляд нічого не змінює: робоче дерево, локальні гілки й гілки відстеження лишаються як були, і на forge нічого не надсилається. Якщо поки ви читаєте, у запит щось відправили або змінили цільову гілку, панель про це скаже й запропонує відкрити його знову. Звичайне клацання по рядку, як і раніше, відкриває запит у браузері.
- **Сповіщення на робочому столі.** Коли Mergelio у фоні, він може повідомити, що завершилося отримання, підтягування, відправлення чи клонування, яке тривало понад 10 секунд, а в разі помилки — чому. Також він може повідомити, що CI пройшов або впав на поточній гілці чи у відкритому пулреквесті, і що пулреквест відкрили, злили або закрили. Клацання по сповіщенню виводить Mergelio на передній план на вкладці цього репозиторію, а сповіщення про пулреквести й CI ще й відкривають запит для перегляду. Типово сповіщення вимкнено. Увімкніть їх у **Налаштуваннях → Сповіщення**: для кожного виду є окремий перемикач, а поріг «довгої операції» можна встановити на 5, 10, 30 або 60 секунд. У **Налаштуваннях → Репозиторій** кожен вид можна перевизначити для окремого репозиторію. Коли сповіщення ввімкнено, Mergelio перевіряє GitHub чи GitLab у фоні лише для відкритих репозиторіїв, робить паузу, поки його вікно у фокусі, і сповільнюється, коли ліміт запитів закінчується. Коли вимкнено, фонових запитів немає.
- Якщо на macOS сповіщення не з'являються, дозвольте їх для Mergelio в **Системних параметрах → Сповіщення**. На Windows під час першого ввімкнення сповіщень додається ярлик у меню «Пуск» — без нього Windows їх не показує. На Linux клацання по сповіщенню поки не перемикає вкладку.

# Змінено

- **Переключення на пулреквест локально більше не зсуває гілки відстеження.** Раніше воно попутно оновлювало `origin/main` або `origin/pr/<n>`, якщо ваш remote відображає refs пулреквестів. Тепер воно отримує лише потрібні коміти.
- На Linux Mergelio тепер потребує libnotify. Пакети `.deb` і `.rpm` встановлюють її самі. Для збирання з вихідного коду встановіть `libnotify-dev` (Debian, Ubuntu) або `libnotify-devel` (Fedora).
