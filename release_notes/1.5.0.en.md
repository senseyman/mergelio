# New

## Automatic updates

- Mergelio asks once whether it may check GitHub for new versions. After that it checks daily.
- When a release is out, a strip appears above the status bar.
- On macOS and Windows the update installs itself. On Linux the strip points you to the download page, because your package manager owns the install.
- Updates are verified before they replace the running app.
- Installing waits while Git is busy, so an update cannot close the app in the middle of a rebase.
