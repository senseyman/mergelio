# New

- **Refresh.** Press `⌘R` (`Ctrl+R` on Windows and Linux), choose **Refresh** in the command palette, or click the refresh button in the Changes panel to re-read the repository. In the terminal, `Ctrl+R` still searches your shell history.
- **The file you are viewing is highlighted.** In a commit's changed files, a comparison and a stash, the file whose diff is open is highlighted, as it already was in the Changes panel.

# Fixed

- Changes made to a repository while its tab was in the background didn't show until the next fetch, and never showed in a repository without a remote. A repository is now re-read when you switch to its tab and when you come back to Mergelio.
- An open diff kept showing a file's old content after the file was changed in another editor. It now updates on its own.
- The diff window stayed open after switching to another repository's tab, still showing the previous repository's file. It now closes.
- Unsaved text in the diff editor was lost without a prompt when you opened another file, switched tabs, went to the Files browser or the dashboard, or quit. It is now kept with its file and comes back when you open that file again, in either view and from either the staged or the unstaged side. Closing the repository's tab, **Close others** and quitting ask about it first.
- Clicking the graph above an open diff now asks about unsaved edits before closing it, like the close button.
- The **Staged** / **Unstaged** switch is hidden while you edit a file in the diff, so it can no longer move the diff off the file you are typing into.
- Each stash drew extra lines that ran to the bottom of the graph. They are gone.
- The uncommitted-changes row was always joined to the top commit in the graph, even when HEAD was further down or on another branch's line. It now sits on HEAD's line and is joined to HEAD, going around a stash or commit in between.
