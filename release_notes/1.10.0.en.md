# New

## Highlights

- **Git hooks.** See which hook rejected your commit, keep your message, and manage hooks in a new panel.
- **Branch review.** Read everything a branch brings in as one scrollable review.
- **Stash panel.** Look inside a stash and apply single files or hunks.
- **Signature checks.** Clear verdicts for signed commits and tags.
- **Image diffs.** Changed images are drawn, not hidden.

## Git hooks

- A commit refused by a hook now names the hook and shows its output. The message you typed is kept, and the composer no longer says "Committed".
- Other actions say "The <hook> hook stopped <action>".
- The composer has a **Skip hooks** toggle. It warns while on, applies to one commit, and is never saved.
- A rejection dialog offers **Manage hooks…** and **Skip hooks for next commit**. Skipping is offered only for hooks it actually skips.
- A refused reword offers **Reword without hooks** as a one-off retry.
- **Git hooks…** in the command palette shows each hook's state, can enable or disable it, edit it, or install it from a sample. It recognises husky, lefthook and pre-commit.

## Branch review

- Open **Review branches…** from the command palette, **Review against current** in the sidebar, or **Open review** in the compare panel.
- Pick a base and a head: a branch, remote branch, tag, worktree or any revision.
- Choose "Since branch point" (the default) or "Tip to tip". The caption names the range.
- The summary shows ahead/behind, file count, added and removed lines, and "N of M viewed". Commits are listed below.
- Each file is a collapsible card with a **Viewed** tick. The tick lapses if that file changes when the head moves.
- The file menu opens the diff viewer, file history or blame. The line menu opens line history.
- Export the range as patch files or copy it as one mbox.
- **Open pull request** shows up when the head branch is on a forge.

## Stash panel

- Selecting a stash opens a panel listing its changes, including untracked files for a stash made with untracked files included. Each file opens its diff without applying anything.
- **Apply to working tree** applies one file. **Apply hunk** in the diff sheet applies one hunk. Both are undoable.
- The stash dialog has a file checklist, **Keep staged changes in place** and **Include untracked files**.
- Rename a stash. The old entry is removed only after the new one is saved.
- **Branch from stash…** is in the panel and the sidebar menu.

## Signatures

- Every signature state has its own label and icon. Only a good signature is green.
- The badge expands to show signer, key, fingerprints, trust and format. When a signature can't be checked, it says why, for example no allowed-signers file or a missing verifier.
- Commit details show signed tags too. Beyond five, use **Verify N more tags**.
- **Check signatures…** in the palette lists commits in a range that have no verified signature.

## Image and binary diffs

- Changed PNG, JPEG, GIF, WebP and BMP images are drawn in four modes: side by side, swipe, onion skin and difference. A summary line shows size changes.
- Other binary files show a hex view of their first 256 bytes, with differing bytes marked.
- Works for commits, comparisons, staged and unstaged changes, and the merge tool's binary-conflict card.
- Files over 32 MiB per side say "too large to preview".

## Other

- Pull request and issue sections show soft placeholder rows instead of a spinner. They hold still when reduced motion is on.

# Fixed

- Staged renames now show as renames in the diff, not as added files.
- A pure rename now counts as a change.
- Diffs of files with spaces or special characters in their names are read correctly.
- Long tag names now fit in the narrowest details panel.
