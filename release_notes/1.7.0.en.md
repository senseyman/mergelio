# New

## GitLab

- The sidebar now works with GitLab.com the same way as with GitHub: merge requests, a pipeline badge on every row, open issues and refresh. Rows open the real page in your browser.
- Preferences → Credentials has one account row per host. Each one connects, checks and removes the token for its own host.
- The refresh interval is one shared setting.
- A failed job that the pipeline allows to fail is not counted as a failure, and a retried job counts only by its latest attempt.
- A project with its issue tracker switched off shows an empty list.
- Next-page links that point to another host or carry credentials are no longer followed.
