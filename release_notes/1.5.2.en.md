# New

- **Merge commits can be reverted and cherry-picked.** When the commit has two or more parents, the graph context menu asks which parent to keep. Each parent is listed with its short hash and subject. Cancelling does nothing.

# Changed

- **Auto-fetch is much gentler.** It now checks every 5 minutes by default, and the interval choices are 30s, 1m, 5m, 15m and 30m. Shorter intervals saved by an older version are raised to 30s.
- Auto-fetch backs off while fetches keep failing, up to 30 minutes, and returns to normal after the first success.
- Auto-fetch pauses while the window is not in focus and fetches as soon as you come back if a check was missed.

# Fixed

- Revert and Cherry-pick failed on every merge commit with "commit is a merge but no -m option was given".
- Code indentation in the diff and merge views was far too narrow on macOS and Windows. Code now uses a proper monospace font.
- Tab-indented files, such as Go and Makefiles, lost their indentation in the diff. Tabs now show as 4-column stops, and copying a line keeps its tabs.
