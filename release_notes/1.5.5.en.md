# New

## Highlights

- **Push to a chosen remote.** Pick the remote, optionally push all tags, and delete tags on a remote.
- **Reset --mixed.** Uncommit and unstage from the commit menu.
- **More conflicts resolvable in the app.** Delete/modify, binary and submodule conflicts.

## Push

- The Push dialog has a **Remote** picker and **Also push all tags**. Force is still behind its confirmation.
- Pushing to a second remote or a fork no longer changes which upstream the branch tracks.
- A repository with no remotes says so, instead of showing an empty picker.
- Tags can now be deleted on a remote.

## Reset

- **Reset here (--mixed)** in the commit menu moves the branch and keeps the commits' changes on disk as unstaged edits.
- Undo restores both the branch and what was staged. The reset is refused while the index has conflicts.

## Conflicts

- Conflicts with no conflict markers, such as a file deleted on one side, binary files and submodules, can now be settled in the app. Choose **Keep mine**, **Keep theirs** or **Delete file**. A side that deleted the file is not offered.
- Binary files are no longer corrupted while resolving.

# Changed

- Mergelio now finds a working Git itself, including Homebrew installs on macOS and the standard Git for Windows locations. When none can run, it names the command that fixes it. Before, a Mac with an unaccepted Xcode licence showed misleading errors on every repository.
- **macOS 10.15 and 11 are no longer supported.** Mergelio now needs macOS 12 or newer.
